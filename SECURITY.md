# Security Policy

## Reporting a vulnerability

Please report security-sensitive findings through GitHub's private vulnerability reporting feature rather than a public issue.

Include the affected browser, a concise reproduction, and the potential impact. Do not include real save data, credentials, or other personal information.

## Data handling

The editor is intended to process save data locally in the browser. It should not transmit, persist, or log save contents. Changes that add telemetry, remote processing, third-party scripts, or persistent browser storage should be clearly disclosed and reviewed before release.
