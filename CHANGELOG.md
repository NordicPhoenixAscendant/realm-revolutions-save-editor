# Changelog

## 1.1.0 — 2026-09-27

- Added next-step assimilation requirements for Elf, Druid, Nomad, Warlock, and Cyclops.
- Added calculated total and remaining BP using the 5 BP base, 15× monster-base progression, and 2.1× per-kill progression.
- Added progress bars driven by the kill counts stored in the loaded save.
- Added the observed step-15 targets for Elf, Nomad, and Cyclops.
- Corrected the Forest and Mountain monster rosters.
- Hardened rendering of save-controlled names, sections, keys, and values.
- Added repository documentation, privacy notes, security guidance, and an MIT license.

## 1.0.0

- Initial standalone Realm Revolutions save editor and analysis dashboard.
